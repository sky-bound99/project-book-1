CHAPTER 6: WEB TECHNOLOGY I

6.1 Introduction to Web Development

Web Development refers to the process of building, creating, and maintaining websites and web applications delivered over the internet via HTTP/HTTPS protocols.

6.2 Web Browsers and Search Engines

  • Web Browser: A client-side software application that requests, fetches, parses, and renders HTML/CSS/JS resources from web servers (e.g., Google Chrome, Mozilla Firefox, Apple Safari).
  • Search Engine: A web-based database service that uses automated crawlers (bots) to index web pages, allowing users to discover content using keyword queries (e.g., Google, Bing, DuckDuckGo).

6.3 Overview of Internet & Web Technologies

  • DNS (Domain Name System): Translates human-readable domain names (example.com) into numeric IP addresses (192.0.2.1).
  • HTTP/HTTPS: Hypertext Transfer Protocol (Secure) handles data exchange between client and server interfaces.

6.4 Content Management Systems (CMS)

A Content Management System (CMS) is a software application that enables users to build, modify, and manage digital content on a website without writing code from scratch (e.g., WordPress, Joomla, Drupal).

6.4 HTML: The Language of the Web

6.4.1 Objectives & 6.4.2 Structure of HTML

HTML (HyperText Markup Language) is the standard markup language used to structure web documents.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Document Title</title>
  </head>
  <body>
    <!-- Page content goes here -->
  </body>
</html>

6.4.3 Publishing and Hosting

  • Web Hosting: Server storage space allocated on connected infrastructure to host website assets publicly.
  • Publishing: Transferring local website code onto a web host using File Transfer Protocol (FTP) or modern continuous integration deployment pipelines.

6.4.4 HTML Tags vs. Attributes

  • Tag: Structural marker defining an element (e.g., <p>).
  • Attribute: Key-value properties contained inside an opening tag that modify behavior or provide metadata (e.g., <a href="index.html" target="_blank">).

6.5 Cascading Style Sheets (CSS)

6.5.1 Introduction to CSS

Cascading Style Sheets (CSS) is a style sheet language used to describe the presentation, layout, colors, and fonts of a document written in HTML.

6.5.2 Inline CSS

Applied directly within an element's HTML opening tag using the style attribute.

<p style="color: blue; font-size: 18px; text-align: center;">
  This text is styled using Inline CSS.
</p>

6.5.3 Embedded (Internal) CSS

Defined within a <style> block placed inside the <head> section of an HTML document.

<!DOCTYPE html>
<html>
<head>
  <style>
    body {
      background-color: #fafafa;
      font-family: Arial, sans-serif;
    }
    .highlight-box {
      background-color: #ffffcc;
      border: 1px solid #e6e600;
      padding: 10px;
    }
  </style>
</head>
<body>
  <div class="highlight-box">Embedded CSS styled box.</div>
</body>
</html>

6.5.4 External CSS

Styles are written in a standalone .css file and linked inside the HTML document's <head> using the <link> element.

1. Style File (styles.css)

/* External Style Sheet */
body {
    margin: 0;
    padding: 0;
    background-color: #ffffff;
}

h1 {
    color: #003366;
    border-bottom: 2px solid #003366;
}

2. HTML Document Linking External File

<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" type="text/css" href="styles.css" />
</head>
<body>
  <h1>Page Styled via External CSS</h1>
</body>
</html>
