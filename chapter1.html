CHAPTER 1
Introduction to Computers and Computer Systems
1.1 Introduction to Computers

A computer is an electronic device operating on the Input-Process-Output (IPO) model: it accepts raw data as input, processes it using stored instructions, and produces meaningful information as output.

1.1.1 Core Characteristics & Applications

Characteristics:

  • Speed: Performs billions of calculations per second (measured in MHz/GHz).
  • Accuracy: High precision; errors usually stem from bad input (Garbage In, Garbage Out / GIGO).
  • Diligence: Works continuously without fatigue, boredom, or loss of concentration.
  • Versatility: Can perform diverse tasks, from word processing to complex simulations.
  • Storage: Holds massive amounts of data in primary and secondary memory.
  • Automation: Executes programmed instructions automatically without manual step-by-step intervention.

Applications:

  • Education: E-learning, research, virtual classrooms.
  • Healthcare: Diagnostic imaging (MRI/CT), patient records, monitoring systems.
  • Banking: ATMs, online transfers, core banking databases.
  • Science & Engineering: CAD modeling, weather forecasting, space exploration.
  • Business: Billing, payroll, inventory control.
1.1.2 Computer Generations

Generation Technology Features & Examples
1st Gen (1940–1956) Vacuum Tubes Huge size, high heat, machine language. Ex: ENIAC, UNIVAC
2nd Gen (1956–1963) Transistors Smaller, faster, used assembly/early languages (FORTRAN, COBOL). Ex: IBM 7094
3rd Gen (1964–1971) Integrated Circuits (ICs) Used silicon chips, keyboards, monitors, operating systems. Ex: IBM System/360
4th Gen (1971–Present) Microprocessors (VLSI/ULSI) Puts CPU on a single chip; PCs, laptops, mobile devices. Ex: Intel Core, Apple M-series
5th Gen (Future & Beyond) AI & Quantum Computing Focuses on machine learning, parallel processing, and natural language. Ex: Supercomputers, Robotics

1.1.3 Storage & Processing Speed Units

Data Storage Units:

  • 1 Bit: Single binary digit (0 or 1)
  • 1 Nibble: 4 bits
  • 1 Byte (B): 8 bits
  • 1 KB: 1,024 Bytes | 1 MB: 1,024 KB | 1 GB: 1,024 MB | 1 TB: 1,024 GB

Processing Speed Units:

  • Clock Speed: Measured in MHz (millions of cycles/sec) or GHz (billions of cycles/sec).
  • Execution Speed: Measured in MIPS (Millions of Instructions Per Second) or FLOPS (Floating-Point Operations Per Second).
1.1.4 Classification of Computers
  • Supercomputers: Fastest and most powerful; used for complex calculations (e.g., weather modeling, space research).
  • Mainframe Computers: High capacity and throughput; handles heavy multi-user transaction processing (e.g., banks, airlines).
  • Minicomputers: Mid-range multi-user systems used by small/medium businesses.
  • Microcomputers: Personal single-user devices (e.g., Desktops, Laptops, Tablets).
1.1.5 Mobile Computing

Technology allowing data transmission wirelessly without a fixed location. Key features are portability, wireless connectivity, and location awareness (GPS).

Applications: Mobile banking (m-wallets), ride-hailing (GPS navigation), mobile shopping, and remote field work.


1.2 Computer Architecture, CPU & Hardware Components

Architecture vs. Organization:

  • Computer Architecture: Design structure visible to a programmer (e.g., Instruction Set Architecture / ISA).
  • Computer Organization: Physical hardware units and operational connections (e.g., bus width, clock frequency).
  • Von Neumann Architecture: Baseline computing model where both data and instructions share the same memory.
1.2.2 Microprocessor & System Components

Core CPU Components:

  • ALU (Arithmetic Logic Unit): Performs calculations (+, -, *) and logical comparisons (AND, OR, NOT).
  • CU (Control Unit): Directs system traffic, fetches, decodes, and manages instruction execution.
  • Registers: High-speed internal memory slots inside the CPU for temporary processing.

System Bus Types:

  • Data Bus (Bidirectional): Carries raw binary data between CPU, memory, and devices.
  • Address Bus (Unidirectional): Sends physical memory addresses driven by the CPU.
  • Control Bus: Transmits control signals (read/write commands, system resets) from the CU.
1.2.5 Primary Memory (Main Memory)
  • RAM (Random Access Memory): Volatile (loses data when powered off); working space for active tasks.
    • SRAM (Static RAM): Fast, expensive, doesn't need refresh; used for Cache Memory.
    • DRAM (Dynamic RAM): Denser, cheaper, requires periodic electrical refreshes; used for main RAM modules.

  • ROM (Read-Only Memory): Non-volatile; stores startup boot instructions (BIOS/UEFI).
    • PROM: Programmable once.
    • EPROM: Erasable via UV light.
    • EEPROM: Electrically erasable and rewritable (modern flash BIOS).

  • Cache Memory: Ultra-fast SRAM sitting between the CPU and main RAM to store frequently used instructions.
  • Buffer: Temporary storage holding data during transfers between devices running at different speeds.
1.2.6 Secondary Memory (Storage)
  • Magnetic Disks (HDD): Uses spinning magnetic platters; high storage capacity at low cost.
  • Flash Memory (SSD / USB Drive): Non-volatile, solid-state chips with no moving parts; much faster than HDDs.
  • Optical Disks: Laser-read media (CD: ~700 MB | DVD: ~4.7 GB | Blu-ray: 25–100 GB).
1.2.7 Input & Output Devices

Common Input Devices:

  • Keyboard & Mouse: Standard text entry and cursor control devices.
  • Scanner / OCR: Converts physical papers or printed text into digital image/text files.
  • OMR (Optical Mark Reader): Reads marked choices on paper sheets (e.g., answer keys).
  • BCR (Barcode Reader): Scans barcode lines for inventory and pricing at checkouts.
  • MICR (Magnetic Ink Character Reader): Reads magnetic ink numbers on bank checks.
  • Touchscreen, Microphone, Digital Camera: Gesture, audio, and visual capture devices.

Common Output Devices:

  • Monitors (Soft-Copy): LCD, LED, or OLED display panels.
  • Printers (Hard-Copy):
    • Impact Printers: Physical contact with paper (e.g., Dot Matrix).
    • Non-Impact Printers: No physical contact (e.g., Inkjet, Laser).
  • Plotters: High-precision vector graphics printers for architectural blueprints.
  • Speakers & Headphones: Audio signal output devices.
