CHAPTER 5: PROGRAMMING CONCEPTS & C PROGRAMMING

5.1 Programming Concepts

5.1.1 Introduction to Programming Languages

A programming language is a standardized set of rules, syntax, and symbols used to instruct a computer system to perform specific tasks. It acts as a bridge between human logic and the machine's underlying hardware execution pipeline.

5.1.2 Low-Level, High-Level, and 4GL Programming Languages

  • Low-Level Languages (1GL & 2GL): Hardware-dependent languages providing minimal abstraction.
    • Machine Language (1GL): Expressed purely in binary (0s and 1s). Executed directly by the CPU without translation.
    • Assembly Language (2GL): Uses human-readable mnemonics (e.g., MOV, ADD, SUB) instead of raw binary strings. Requires an assembler.
  • High-Level Languages (3GL): Machine-independent languages using natural English keywords and mathematical notation (e.g., C, C++, Java, Python). They require compilers or interpreters.
  • Fourth-Generation Languages (4GL): Non-procedural, domain-specific languages designed to reduce programming effort by specifying what output is needed rather than how to compute it (e.g., SQL, MATLAB, SAS).

5.1.3 Compiler, Interpreter, and Assembler

Translator Input Code Execution Mechanism Error Detection
Assembler Assembly Language Converts mnemonics directly into absolute machine binary. Low-level syntax errors.
Compiler High-Level Language Translates entire source code into machine code in one pass, producing an executable object file. Reports all errors after compilation completes.
Interpreter High-Level Language Translates and executes source code line-by-line in real time without generating a standalone executable. Stops execution at the first line containing an error.

5.1.4 Syntax, Semantic, and Runtime Errors

  • Syntax Error: Violations of the language's grammatical rules (e.g., missing semicolons, unmatched parentheses). Caught during compilation.
  • Semantic (Logical) Error: Code runs to completion without crashing, but yields incorrect outputs due to flawed logic (e.g., writing area = width + height instead of multiplication).
  • Runtime Error: Flaws triggered during program execution, causing crash events (e.g., division by zero, accessing out-of-bounds memory addresses).

5.1.5 Control Structures: Sequence, Selection, and Iteration

  • Sequence: Default execution flow where statements execute step-by-step from top to bottom.
  • Selection (Branching): Executes specific code blocks conditionally based on logical criteria (e.g., if-else, switch).
  • Iteration (Looping): Repeats a code block until a specified termination condition becomes false (e.g., while, for).

5.1.6 Program Design Tools – Algorithm, Flowchart, and Pseudocode

Problem: Compute the factorial of a given positive integer $N$.

1. Algorithm

Step 1: Start
Step 2: Read integer input N
Step 3: Initialize fact = 1, i = 1
Step 4: If i > N, jump to Step 7
Step 5: Compute fact = fact * i
Step 6: Increment i = i + 1, jump to Step 4
Step 7: Print fact
Step 8: Stop

2. Pseudocode

BEGIN
  READ N
  SET fact = 1
  FOR i = 1 TO N DO
    fact = fact * i
  END FOR
  PRINT fact
END

3. Flowchart Representation (Textual Model)

[Start] ──> [Input N] ──> [fact = 1, i = 1] ──> < Is i <= N? >
                                                   │       │
                                                 (Yes)    (No)
                                                   │       │
                                                   ▼       ▼
                                         [fact = fact * i] [Print fact]
                                         [i = i + 1]       │
                                                   │       ▼
                                                   └───> [Stop]

5.1.7 Absolute Binary, BCD, ASCII, and Unicode

  • Absolute Binary: Pure positional base-2 numerical representation using bits 0 and 1.
  • Binary-Coded Decimal (BCD): Encodes each decimal digit ($0$ through $9$) separately into a fixed 4-bit binary nibble (e.g., decimal $25_{10}$ becomes 0010 0101 in BCD).
  • ASCII (American Standard Code for Information Interchange): A 7-bit character encoding standard supporting up to $128$ characters ($2^7$), limited primarily to English characters and basic symbols.
  • Unicode: A universal character encoding standard (e.g., UTF-8, UTF-16) designed to represent scripts, languages, and symbols across all global writing systems (supporting over $140,000$ characters).

5.2 C Programming Language

5.2.1 Introduction and Features of C

Developed by Dennis Ritchie at Bell Labs in 1972, C is a structured, procedural high-level programming language renowned for its balance of abstraction and direct memory manipulation capability via pointers.

  • Key Features: Mid-level control capabilities, modularity via functions, extensive built-in operators, fast execution speed, and high portability across platform architectures.

5.2.2 Structure of a C Program

/* 1. Documentation Section */
// Program to compute area of a circle

/* 2. Link / Preprocessor Section */
#include <stdio.h>

/* 3. Definition Section */
#define PI 3.14159

/* 4. Global Declaration Section */
float area;

/* 5. Main Function Section */
int main(void) {
    /* Local Variable Declarations */
    float radius = 5.0;

    /* Executable Statements */
    area = PI * radius * radius;
    printf("Calculated Area: %.2f\n", area);

    /* Return Statement */
    return 0;
}

/* 6. User-Defined Functions Section (If applicable) */

5.2.3 C Preprocessor and Header Files

The C Preprocessor is a macro processor that scans source code before compilation begins. Lines beginning with # are preprocessor directives.

  • #include <stdio.h>: Copies standard Input/Output library declarations into the program.
  • #define MACRO_NAME value: Substitutes macro tokens throughout the file before compilation.

5.2.4 Character Set, 5.2.5 Comments, 5.2.6 Tokens, Keywords, and Identifiers

  • Character Set: Letters (A-Z, a-z), Digits (0-9), Special Symbols (+, -, *, &, %), and Whitespace characters.
  • Comments: Ignored by the compiler.
    • Single-line comment: // comment
    • Multi-line comment: /* comment */
  • Tokens: The smallest individual units in a program (Keywords, Identifiers, Constants, Strings, Special Symbols, Operators).
  • Keywords: Reserved words with predefined meanings (32 standard keywords in C89, e.g., int, return, if, volatile).
  • Identifiers: User-defined names for variables, functions, and arrays. Must begin with a letter or underscore.

5.2.10 Simple and Compound Statements

  • Simple Statement: A single instruction ending with a semicolon: x = 10;
  • Compound Statement (Block): A group of statements enclosed in curly braces { ... } executed sequentially.

5.2.11 Operators and Expressions

C provides rich support for operator-driven expressions:

  • Arithmetic: +, -, *, /, % (Modulo, yields remainder).
  • Relational: ==, !=, >, <, >=, <= (Evaluates to 1 [true] or 0 [false]).
  • Logical: && (AND), || (OR), ! (NOT).
  • Assignment: =, +=, -=, *=, /=, %=
  • Unary: ++ (Increment), -- (Decrement), sizeof
  • Conditional (Ternary): expression1 ? expression2 : expression3

5.2.12 Input/Output (I/O) Functions

  • Formatted I/O: printf("format string", variables...), scanf("format string", &variables...)
  • Unformatted I/O: getchar(), putchar(), gets() (deprecated), puts().

5.2.13 Selection Control Statements

#include <stdio.h>

int main(void) {
    int score = 85;

    // if-else-if ladder
    if (score >= 90) {
        printf("Grade A\n");
    } else if (score >= 80) {
        printf("Grade B\n");
    } else {
        printf("Grade C\n");
    }

    // Switch case selection
    int category = 2;
    switch (category) {
        case 1:
            printf("Category 1 Selected\n");
            break;
        case 2:
            printf("Category 2 Selected\n");
            break;
        default:
            printf("Invalid Category\n");
    }

    return 0;
}

5.2.14 Iteration Control Statements (Loops)

#include <stdio.h>

int main(void) {
    int i;

    // 1. For Loop
    for (i = 0; i < 3; i++) {
        printf("For Loop i = %d\n", i);
    }

    // 2. While Loop (Entry-Controlled)
    int j = 0;
    while (j < 3) {
        printf("While Loop j = %d\n", j);
        j++;
    }

    // 3. Do-While Loop (Exit-Controlled)
    int k = 0;
    do {
        printf("Do-While Loop k = %d\n", k);
        k++;
    } while (k < 3);

    return 0;
}

5.2.15 Array Processing & Matrix Operations

An array is a fixed-size collection of homogenous elements stored in contiguous memory locations.

2D Matrix Addition and Subtraction Example

#include <stdio.h>

int main(void) {
    int A[2][2] = {{5, 8}, {3, 4}};
    int B[2][2] = {{1, 2}, {7, 3}};
    int Sum[2][2], Diff[2][2];

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            Sum[i][j] = A[i][j] + B[i][j];
            Diff[i][j] = A[i][j] - B[i][j];
        }
    }

    printf("Sum Matrix cell [0][0]: %d\n", Sum[0][0]);   // Outputs 6
    printf("Diff Matrix cell [0][0]: %d\n", Diff[0][0]); // Outputs 4

    return 0;
}

5.2.16 String Manipulation and String Functions

In C, a string is a one-dimensional array of characters terminated by a null character ('\0').

#include <stdio.h>
#include <string.h>

int main(void) {
    char str1[50] = "Hello";
    char str2[50] = "World";
    char temp[50];

    // 1. strlen() - Length of string
    printf("Length of str1: %lu\n", strlen(str1)); // 5

    // 2. strcpy() - Copy string
    strcpy(temp, str1);

    // 3. strcat() - Concatenate strings
    strcat(str1, str2); // str1 becomes "HelloWorld"
    printf("Concatenated: %s\n", str1);

    // 4. strcmp() - Compare strings lexicographically
    if (strcmp(temp, "Hello") == 0) {
        printf("Strings are identical\n");
    }

    // 5. Non-standard extensions (strrev, strlwr, strupr)
    // Note: strlwr/strupr/strrev exist in standard string.h on POSIX/GNU platforms via lowercase loops:
    return 0;
}
