CHAPTER 3: Software, Operating Systems, and Desktop Environments

3.1 Concept of Software

Software is a set of instructions or programs that tell a computer what to do. Without software, hardware cannot do anything.

3.1.1 Categories of Software

  1. System Software

    Runs the computer hardware and application programs. Examples: Operating systems (Windows, Linux), Device Drivers, and Language Translators.

  2. Utility Software

    Helps maintain, clean, and protect the computer. Examples: Antivirus (Windows Defender), Disk Cleanup, and File Compression tools (WinRAR).

  3. Application Software

    Programs used by people to do specific daily tasks. Examples: Word processors (Microsoft Word), Spreadsheets (Excel), and Paint.

  4. Web-Based Applications

    Apps that run on the internet through a web browser without needing local installation. Examples: Google Docs, Canva, and Figma.

  5. Mobile Apps

    Applications designed to run on smartphones and tablets. Examples: WhatsApp, TikTok, and Instagram.

3.2 Concept of Operating System

3.2.1 What is an Operating System?

An Operating System (OS) is the main software that acts as a bridge between the user, applications, and the computer hardware. Examples include Microsoft Windows, macOS, and Linux.

3.2.2 Functions of an Operating System

  • Processor Management: Decides which program uses the CPU and for how long.
  • Memory Management: Tracks and manages RAM usage for all running programs.
  • File Management: Organizes files, folders, and drives on the computer.
  • Device Management: Manages connected devices like keyboards, mice, and printers using drivers.
  • Security: Protects the computer using passwords and user accounts.

3.3 Windows Operating System

3.3.1 Desktop and Windows Environment

Windows uses a Graphical User Interface (GUI) with icons, windows, and a mouse so users don't have to type complex text commands.

  • Desktop: The main screen showing icons and wallpaper.
  • Taskbar: The bar at the bottom with the Start button, open apps, and the clock.
  • Window Controls: Minimize (-), Maximize/Restore ([]), and Close (X).

3.3.2 Managing Files and Folders

File Explorer is used to manage files. Basic shortcuts include:

  • Copy: Ctrl + C
  • Paste: Ctrl + V
  • Cut / Move: Ctrl + X
  • New Folder: Ctrl + Shift + N
  • Delete: Moves item to the Recycle Bin.

3.4 Open Source Operating Systems

An Open Source operating system is free to use, and its source code is open for anyone to view, edit, and improve. The most popular example is Linux.
