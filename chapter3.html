CHAPTER 3

Software, Operating Systems, and Desktop Environments

3.1 Concept of Software

Software consists of the complete set of instructions, data structures, scripts, and programs that direct computer hardware to execute specific tasks. While hardware represents the physical components of a system (such as silicon microchips, circuit boards, and storage drives), software acts as the logical layer that brings these physical devices to life, governing how data is captured, manipulated, stored, and communicated.

3.1.1 Definition of Software

Software is formally defined as an organized collection of computer code, procedures, algorithms, and associated documentation that instructs a central processing unit (CPU) on how to process input data into meaningful output information. Software is intangible; it resides electronically within volatile memory (RAM) or non-volatile storage media (SSD, Hard Drives) as binary machine code executed directly by hardware logic circuits.

3.1.2 Categories of Software

Software is broadly classified into five major operational categories based on its proximity to the underlying hardware, deployment environment, and intended operational function:

1. System Software

System software provides the foundational platform required to run a computer's hardware and execute higher-level application programs. It operates in the background, managing low-level hardware interactions, system resources, and memory allocation without requiring constant human intervention.

  • Operating Systems: Manages system hardware, files, and running processes.
    Examples: Microsoft Windows 11, macOS Sequoia, Linux Kernel, Ubuntu.
  • Device Drivers: Specialized micro-programs that enable the operating system to communicate directly with physical peripheral devices.
    Examples: NVIDIA GeForce display drivers, Realtek audio drivers, HP LaserJet printer controllers.
  • Language Translators: Translates human-written high-level programming code into binary machine code executed by microprocessors.
    Examples: Compilers (GCC, Clang), Interpreters (Python Interpreter), Assemblers.

2. Utility Software

Utility software consists of service programs designed to analyze, configure, optimize, maintain, and safeguard computer hardware, operating systems, and stored files. Unlike system software, utility software is typically invoked directly by users to perform system maintenance tasks.

  • Antivirus & Security Utilities: Scans, detects, quarantines, and removes malware threats.
    Examples: Windows Defender, Bitdefender, Malwarebytes.
  • Disk Management Utilities: Formats, partitions, defragments, and analyzes hard disk storage sectors.
    Examples: Windows Disk Management, EaseUS Partition Master.
  • File Compression Utilities: Reduces file sizes for efficient storage or network transmission using compression algorithms.
    Examples: WinRAR, 7-Zip, WinZip.
  • Backup Utilities: Automated tools for duplicating critical files to external or cloud media.
    Examples: Acronis Cyber Protect, Macrium Reflect.

3. Application Software

Application software consists of end-user programs created to assist individuals or businesses in completing specific tasks, such as generating documents, editing multimedia assets, analyzing data, or playing games.

  • Word Processors: Used for drafting, editing, and formatting text documents.
    Examples: Microsoft Word, LibreOffice Writer, Google Docs.
  • Spreadsheet Software: Organizes quantitative data into tabular grids to perform complex financial and mathematical calculations.
    Examples: Microsoft Excel, Apache OpenOffice Calc.
  • Database Management Systems (DBMS): Stores, structures, queries, and manages large volumes of relational data.
    Examples: Oracle Database, MySQL, Microsoft Access.
  • Graphic Design & Multimedia Suites: Used for editing photos, vector graphics, and video rendering.
    Examples: Adobe Photoshop, Premiere Pro, Blender, GIMP.

4. Web-Based Applications

Web-based applications are software programs that run on remote server infrastructure and are accessed by users over a local network or the Internet using a standard web browser interface. Web apps do not require local installation on the client computer, relying instead on cloud servers for data processing and database management.

  • Office & Productivity Suites: Google Workspace (Google Sheets, Google Slides), Microsoft 365 Web Apps.
  • Collaboration & Project Management: Trello, Asana, Notion, Slack Web interface.
  • E-Commerce & Service Dashboards: Canva (online image design), Figma (UI/UX design).

5. Mobile Apps

Mobile applications are software packages engineered specifically to execute on compact handheld mobile hardware (smartphones, smartwatches, and tablets). They are optimized for touch-screen input, limited battery power reserves, mobile cellular connectivity, and location-based GPS services.

  • Native Mobile Apps: Built exclusively for a target mobile operating system using specific platform languages (e.g., Swift for iOS, Kotlin for Android).
    Examples: Apple Maps, WhatsApp Mobile.
  • Hybrid / Cross-Platform Mobile Apps: Web-technologies wrapped inside a native shell to run across multiple mobile operating systems.
    Examples: Uber, Instagram, eSewa, TikTok.

3.2 Concept of Operating System

3.2.1 Introduction to Operating System

An Operating System (OS) is the foundational system software program that acts as an intermediary bridge between user applications and physical computer hardware. Without an operating system, a computer is an unusable assembly of electronic components, as users would have to write complex low-level machine code instructions to execute even basic tasks like reading data from a hard drive or outputting text to a monitor.

3.2.2 Role of Operating System

The operating system fulfills three main roles within a computer system architecture:

  • Government / Administrator Role: Allocates hardware resources (CPU time, RAM capacity, disk storage space, external I/O connections) fairly and efficiently among competing software processes.
  • Resource Allocator: Resolves conflicting requests for system resources to prevent deadlocks, data corruption, and system crashes.
  • Control Program: Monitors the execution of user programs to prevent system errors, unauthorized access, and hardware misuse.

3.2.3 Functions of an Operating System

An operating system manages system operations across several core functional areas:

  • 1. Processor Management (CPU Scheduling):
    Decides which running process gets access to the CPU core, for how long, and in what order. Uses scheduling algorithms such as First-Come, First-Served (FCFS), Shortest Job First (SJF), and Round Robin (RR) to maximize CPU utilization.
  • 2. Memory Management:
    Tracks every byte of primary memory (RAM), recording whether it is free or allocated to a specific program. Dynamically allocates RAM blocks when applications launch and reclaims that memory space when programs close. Manages Virtual Memory by swapping inactive data onto hard disk storage when physical RAM is exhausted.
  • 3. File Management:
    Organizes stored data into logical file structures (files and directory trees). Manages disk file systems (such as NTFS, FAT32, ext4), controlling read/write access permissions, file creation, deletion, renaming, and directory navigation.
  • 4. Device Management (I/O Management):
    Coordinates communication with external peripheral hardware (keyboards, printers, storage drives) using specialized device drivers and I/O controllers. Manages data buffering, caching, and printing queues (spooling).
  • 5. Security and Protection:
    Enforces access control policies to safeguard stored data against unauthorized intrusion. Requires password/biometric user authentication, prevents unauthorized programs from overwriting system memory, and isolates running processes from one another.
  • 6. User Interface Provision:
    Provides an interactive interface through which human operators issue commands to the computer. This interface can be a text-based Command Line Interface (CLI) like MS-DOS or an intuitive Graphical User Interface (GUI) like Windows.

3.2.4 Operating System Terminology

Modern operating systems use distinct execution techniques to optimize performance based on system architecture:

  • Multiprogramming:
    A technique where multiple software programs are loaded into main memory (RAM) simultaneously. The CPU executes one program at a time; if that program pauses to wait for an input/output operation to complete (such as reading a file from a hard drive), the operating system immediately switches the CPU to another program sitting in memory. This prevents the CPU from sitting idle during I/O delays.
    Example: Early mainframe batch processing systems loading multiple calculations into memory at once.
  • Multitasking (Time-Sharing):
    A logical extension of multiprogramming where the CPU switches between active tasks so rapidly (using small time slices called quanta) that users can interact with multiple applications running simultaneously without noticing lag.
    Example: Editing a Word document while downloading a video file and listening to music on a desktop PC.
  • Multiprocessing:
    A computing system architecture that uses two or more physical processing units (CPU cores or separate microprocessors) operating together to execute multiple program instructions simultaneously.
    Example: A multi-core workstation processor (e.g., AMD Ryzen 16-Core or Intel Core i9) running multi-threaded 3D video rendering tasks across separate hardware cores concurrently.
  • Distributed Operating System:
    An operating system configuration where multiple independent physical computers, interconnected via high-speed networks, coordinate their operations to appear to users as a single unified system. Processing loads and data storage are distributed across multiple remote server nodes.
    Example: Apache Hadoop clusters, cloud computing infrastructure (AWS EC2 instances), and enterprise computational grid systems.

3.3 Windows Operating System

3.3.1 Introduction to GUI-Based Operating System and Its Features

A Graphical User Interface (GUI) operating system allows users to interact with computer hardware using visual elements—such as windows, icons, menus, buttons, and pointers (known as the WIMP paradigm)—instead of typing complex text-based commands into a terminal prompt.

Key Features of modern GUI Operating Systems (e.g., Microsoft Windows):

  • Visual Interaction: Graphical icons represent files, applications, and system settings, making navigation intuitive.
  • WYSIWYG ("What You See Is What You Get"): Screen displays accurately preview how printed documents or rendered graphics will look.
  • Multitasking Window Management: Allows multiple application windows to be opened, minimized, resized, tiled, or stacked on screen simultaneously.
  • Plug and Play (PnP) Support: Automatically detects, configures, and installs appropriate drivers for newly connected USB hardware peripherals.
  • Standardized UI Controls: Uses consistent UI elements (drop-down menus, radio buttons, dialogue boxes, scrollbars) across third-party software applications.

3.3.2 Working in Desktop Application and Window Environment

The Windows desktop environment serves as the primary workspace for launching programs and organizing files. Key desktop components include:

  • The Desktop Workspace: The background area displaying icons, shortcuts, open windows, and wallpaper images.
  • The Taskbar: Located at the screen edge, it displays currently active application buttons, pinned program shortcuts, the Start Menu button, and the System Tray (Notification Area displaying clock, volume, and network status).
  • Window Controls: Application windows feature a standard top title bar housing three essential window manipulation control buttons:
    • Minimize Button (_): Collapses the open window onto the bottom taskbar while keeping the program running in memory.
    • Maximize / Restore Button (square): Expands the window to fill the entire display screen or restores it to its previous scaled size.
    • Close Button (X): Terminates the active window and frees its assigned system memory.

3.3.3 Manage Files and Folders with File Explorer

File Explorer (formerly Windows Explorer) is the graphical file management tool used to navigate, organize, copy, move, rename, and search physical hard drive storage directories.

Core File Management Tasks in File Explorer:

  • Creating Folders: Right-click within a directory window, navigate to New -> Folder, or use the keyboard shortcut Ctrl + Shift + N to create organized storage directories.
  • Copying vs. Moving Data:
    • Copying: Duplicates a file/folder to a new destination while retaining the original file in its initial location (Shortcut: Ctrl + C to copy, Ctrl + V to paste).
    • Moving (Cut): Relocates a file/folder to a new destination while removing it from its original location (Shortcut: Ctrl + X to cut, Ctrl + V to paste).
  • Renaming Files: Right-click a target file, select Rename, or press F2 to update its name while preserving its file extension.
  • Deleting Data: Pressing Delete moves a file to the temporary Recycle Bin, allowing recovery. Pressing Shift + Delete bypasses the Recycle Bin, permanently purging the data from physical disk sectors.

3.3.4 Customize the Start Screen and Desktop

Windows allows users to customize their visual interface for improved workspace organization and productivity:

  • Personalization Settings: Accessing Settings -> Personalization allows users to change desktop background wallpaper, system dark/light themes, accent colors, and lock screen graphics.
  • Customizing the Start Menu: Pinning frequently used business applications directly to the Start Menu layout for quick access, reorganizing application groupings, or adjusting Start Menu grid sizes.
  • Desktop Shortcuts: Creating custom desktop icons linking to deep system file directories, executable files, or web links by right-clicking an item and selecting Send to -> Desktop (create shortcut).

3.3.5 Installing and Removing Devices

Managing external peripherals (printers, scanners, audio devices) and internal expansion components involves driver setup and hardware removal protocols:

  • Installing Peripheral Hardware: Modern USB devices rely on Plug-and-Play standards. When plugged in, the OS identifies the device's hardware ID and automatically installs matching signed drivers from the Windows Update online repository. Manual installation uses setup wizard utilities provided by manufacturers.
  • Removing Hardware Devices: Accessing Settings -> Bluetooth & Devices -> Devices allows users to select connected hardware (such as Bluetooth headsets or local printers) and click Remove Device to clear associated software bindings.
  • Safe Ejection of Storage Media: USB mass storage drives must be unmounted using the "Safely Remove Hardware and Eject Media" icon in the system tray before physical disconnection to prevent data corruption in write-cache buffers.

3.3.6 Manage Passwords and Privacy Levels

Protecting user accounts and system data against unauthorized local access requires configuring credentials and privacy controls:

  • User Account Password Management: Configured under Settings -> Accounts -> Sign-in Options. Windows supports traditional alphanumeric passwords, custom Security PINs, and Windows Hello biometric authentication (facial recognition or fingerprint scanning).
  • Privacy Settings Control: Managed under Settings -> Privacy & Security. Users can grant or revoke application permissions to access hardware peripherals (webcam, microphone), location tracking GPS chips, contacts, and telemetry diagnostic data collection.

3.3.7 Use of Control Panel, System Tools, and Accessories

1. Control Panel:
The legacy administrative management dashboard in Windows containing applets used to adjust deep system configurations, control user accounts, set up network connections, configure system security, and modify hardware settings.

2. System Tools:

  • Task Manager (Ctrl + Shift + Esc): Displays real-time CPU, RAM, Disk, and Network usage metrics. Used to force-close unresponsive application processes, manage system startup programs, and monitor system resources.
  • Disk Cleanup: A built-in utility that scans hard disk partitions to calculate and remove temporary system files, internet caches, installer logs, and contents of the Recycle Bin to free up disk space.
  • Defragment and Optimize Drives: Consolidates fragmented data blocks on traditional mechanical Hard Disk Drives (HDDs) to speed up file read access, or runs TRIM optimization commands on Solid State Drives (SSDs).

3. Windows Built-in Accessories:

  • Notepad: A lightweight plain-text editor used to write basic text files or edit source code without formatting overhead.
  • Paint / Paint 3D: A basic raster graphics editor used for quick image cropping, drawing, and resizing.
  • Snipping Tool: A screen capture utility used to record videos or capture screen regions, annotate screenshots, and save image files.

3.4 Open Source and Mobile Operating Systems

3.4.1 Concept of Open Source Operating Systems

An Open Source Operating System is an operating system whose underlying source code is made freely available to the public under open-source licenses (such as the GNU General Public License - GPL). Users, software developers, and system administrators are granted legal rights to view, modify, customize, debug, compile, and redistribute the operating system code without paying licensing fees to a proprietary vendor.

Comparison: Open Source vs. Proprietary Operating Systems:

Attribute Open Source OS (e.g., Linux) Proprietary OS (e.g., Windows, macOS)
Source Code Access Fully public; anyone can view, audit, and modify the code. Closed; source code is kept secret by the owning corporation.
Licensing Cost Free to download, deploy, and redistribute (FOSS model). Requires paid user licenses, activation keys, or subscription fees.
Development Model Community-driven global developer networks. In-house corporate development teams.
Customizability Extremely high; can modify the system down to the kernel level. Restricted to user preferences allowed by the vendor UI.

3.4.2 Introduction to Linux and UNIX

UNIX Operating System:
Developed in 1969 by Ken Thompson, Dennis Ritchie, and others at AT&T Bell Labs, UNIX is a powerful, multi-user, multitasking, command-line-driven operating system written primarily in the C programming language. Built around a modular philosophy, UNIX introduced concepts like hierarchical file systems, pipes, command shells, and networking protocols (TCP/IP). Modern enterprise UNIX implementations include IBM AIX, HP-UX, and Oracle Solaris.

Linux Operating System:
In 1991, Finnish computer science student Linus Torvalds created a free, open-source UNIX-like kernel named Linux. Combining his new kernel with the pre-existing tools of Richard Stallman's GNU Project created the complete, fully functional GNU/Linux operating system. Linux adopts UNIX architectural concepts, operating reliably across everything from microcontrollers and single-board computers (Raspberry Pi) to supercomputer processing clusters and cloud servers.

3.4.3 Linux Distributions (Distros)

Because the core Linux Kernel is just the underlying engine that manages hardware memory and CPU tasks, operating system bundles called Linux Distributions (Distros) package the kernel alongside system utilities, graphical desktop environments (GNOME, KDE Plasma), package management tools, and pre-installed application software for easy installation.

Major Linux Distributions and Their Primary Uses:

  • Ubuntu (Canonical):
    The most popular user-friendly Linux distribution. Features a polished desktop user interface, extensive software support, and an active community forum. Ideal for beginners, software developers, and cloud web servers.
  • Fedora (Red Hat Community):
    A community-supported distribution focused on integrating the latest cutting-edge software updates, security features, and open-source innovations. Serves as the upstream testing platform for enterprise Linux technologies.
  • Debian:
    Known for its exceptional stability, testing rigor, and commitment to free open-source software principles. Uses the .deb package format and apt package manager. Serves as the base distribution upon which Ubuntu and Linux Mint are built.
  • Red Hat Enterprise Linux (RHEL):
    A commercial, enterprise-grade Linux distribution built for stability, security compliance, and long-term corporate software support. Common in enterprise server farms, bank infrastructures, and corporate data centers.
  • Kali Linux (Offensive Security):
    A specialized Debian-derived distribution pre-configured with hundreds of security auditing, penetration testing, network packet sniffing, and digital forensics tools used by cybersecurity professionals.

3.4.4 Concept of Mobile Operating Systems

A Mobile Operating System is software optimized to run on portable, battery-powered handheld computing devices such as smartphones, smartwatches, and tablet computers. Mobile operating systems prioritize energy efficiency, touch interface controls, wireless connectivity management (5G, LTE, Wi-Fi, Bluetooth), integrated GPS navigation capabilities, and app ecosystem security sandboxing.

3.4.5 Types of Mobile Operating Systems

1. Android OS (Google):
An open-source mobile operating system developed by Google, built on top of a modified Linux Kernel. Android powers the majority of global smartphones due to its licensing flexibility across hardware manufacturers (Samsung, Xiaomi, Google Pixel, Motorola).

  • Key Characteristics: Highly customizable user interfaces, support for third-party application stores, open-source codebase (Android Open Source Project - AOSP), app distribution via the Google Play Store, and deep integration with Google cloud services.

2. iOS (Apple):
A proprietary, closed-source mobile operating system developed exclusively by Apple Inc. for its iPhone device lineup (derived from Apple’s desktop macOS core).

  • Key Characteristics: Closed platform ecosystem, high optimization between hardware and software, strong privacy controls, consistent long-term OS updates, and app distribution via the Apple App Store.

3. Specialized / Legacy Mobile Operating Systems:

  • iPadOS: Apple's dedicated mobile OS derived from iOS, optimized specifically for large-screen iPad tablets with multi-window multitasking and stylus input support.
  • watchOS / Wear OS: Compact, low-power mobile operating systems designed by Apple and Google respectively to power smartwatches and fitness wearables.
  • Legacy Platforms: Historical mobile operating systems that pioneered the industry, including Symbian OS (Nokia), BlackBerry OS, Windows Phone/Mobile (Microsoft), and Palm OS.
